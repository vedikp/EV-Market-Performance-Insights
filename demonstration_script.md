# Demonstration Video Script (Target: 8–10 Minutes)

| **Time**       | **Screen**                                      | **Say**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| -------------- | ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **0:00–0:45**  | Title slide / Website homepage                  | "Hello everyone! My name is Samarth Bhargav. This project is about Superstore Sales and Profit Analysis using Tableau. In this video, I will demonstrate the dataset, data cleaning, Excel analysis, Tableau dashboard, Tableau story, performance testing, and the final website."                                                                                                                                                                                                                                                                                                      |
| **0:45–1:30**  | Project folder + `data/original`                | "The source is a public Superstore CSV dataset containing approximately 8,399 order lines from 2009 to 2012. It includes information about orders, customers, products, sales, profits, discounts, shipping methods, and regions. I kept the original dataset unchanged and verified it using a hash to maintain data integrity."                                                                                                                                                                                                                                                        |
| **1:30–2:30**  | `data_quality_report.md` + `clean_data.js`      | "For data cleaning, I used JavaScript with Node.js. The script corrected region and province spelling mistakes, converted dates into the proper format, and added derived fields. No rows were removed during this process. I also created a data quality report to document the cleaning process and maintain a record of the changes."                                                                                                                                                                                                                                                 |
| **2:30–3:30**  | Excel workbook                                  | "The Excel workbook contains the data dictionary, cleaned dataset, KPI formulas, and analysis sheets. These sheets help organize the information and calculate important business indicators such as sales, profit, order counts, and profit-related measurements. I also checked the formulas against an independent recalculation to verify their correctness."                                                                                                                                                                                                                        |
| **3:30–4:30**  | Tableau calculated fields                       | "In Tableau, I created several calculated fields, including profit margin, discount band, distinct orders, and loss share. I also used a Level of Detail calculation, known as LOD, and a parameter to make the analysis more flexible. These calculations help us understand business performance and profitability in greater detail."                                                                                                                                                                                                                                                 |
| **4:30–6:00**  | Tableau dashboard                               | "Now, let's explore the interactive dashboard. At the top, we have important KPIs. Below them, we have visualizations showing sales trends, category-wise profit, geographical performance, discount analysis, and shipping modes. These charts help us understand different aspects of business performance. Now, I will click on Furniture. As you can see, the dashboard updates according to the selected category. This makes the dashboard interactive. I have also created a phone layout where the visualizations are arranged vertically for better viewing on mobile devices." |
| **6:00–7:30**  | Tableau Story                                   | "Along with the dashboard, I created a Tableau Story containing six points. These points explain the overall business performance, sales trends, category-wise profit, geographical performance, discount analysis, and shipping methods. Each point presents an important finding from the analysis. The story helps users understand the results in a step-by-step manner, while the dashboard allows them to explore the data independently."                                                                                                                                         |
| **7:30–8:30**  | Performance test plan + results                 | "I also performed performance testing to understand how different factors affect the dashboard. I tested four factors: data volume, filters, calculated fields, and the number of charts. These tests help identify possible performance issues and areas for improvement. Here, you can see the performance testing plan and the recorded results."                                                                                                                                                                                                                                     |
| **8:30–9:30**  | Live GitHub Pages website                       | "Finally, let's explore the project website. The website provides access to the published Tableau dashboard and Tableau Story. This website brings all the important project components together in one place."                                                                                                                                                                                                    |
| **9:30–10:00** | Key findings / Website homepage / Closing slide | "The key finding of this project is that Furniture, truck shipping, and higher discounts are associated with thinner profit margins in the analyzed dataset. Overall, this project demonstrates the complete data analytics workflow, from raw data cleaning to interactive dashboards and website integration. Thank you for watching my project demonstration!"                                                                                             |
